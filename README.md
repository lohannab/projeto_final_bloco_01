## 🎯 Objetivo

Desenvolver um sistema de e-commerce (tipo de produto à escolha) baseado na lógica de um sistema bancário, implementando funcionalidades de **CRUD completo** (Create, Read, Update, Delete) com os pilares da Programação Orientada a Objetos.

---

## 🛠️ Tecnologias & Conceitos Aplicados

| Categoria | Detalhes |
|-----------|----------|
| **Linguagem** | JavaScript / TypeScript |
| **Paradigma** | Programação Orientada a Objetos (POO) |
| **Versionamento** | Git com estratégia de branches |

### Conceitos de POO utilizados:

- 🧱 **Classes** — Abstratas e Estendidas
- 🔗 **Interfaces** e **Repositories**
- 🔄 **Herança**, **Polimorfismo** e **Sobrecarga**
- 📦 **Collections** e **Exceptions**

---

## 📂 Estrutura & Etapas de Desenvolvimento

O projeto foi dividido em etapas com branches dedicadas:

```
main
├── 📌 Menu              → Estrutura inicial e navegação
├── 📌 Model_Repository  → Classes, atributos e interfaces
└── 📌 Controller        → Lógica de negócio e tratamento de erros
```

### Etapa 1 — Menu `branch: Menu`
> Estrutura inicial do projeto, variáveis, laços condicionais e de repetição. Interface de navegação interativa via console.

### Etapa 2 — Model & Repository `branch: Model_Repository`
> Criação das classes principais com seus atributos e métodos. Definição das interfaces e camada de repositório de dados.

### Etapa 3 — Controller `branch: Controller`
> Implementação da lógica de negócio completa, coleções de dados e tratamento de erros com exceptions.

### ✦ Extras
> Funcionalidades adicionais implementadas para enriquecer a experiência do usuário.

---

## 📋 Requisitos Mínimos Implementados

- [x] Pelo menos **1 Classe Abstrata** e **1 Classe Estendida**
- [x] **Menu Inicial** interativo para execução das funcionalidades
- [x] **CRUD completo** de produtos (Create, Read, Update, Delete)
